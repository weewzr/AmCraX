| LCOH | Levelised cost of hydrogen |
| LHV | Lower heating value |
| LMTD | Logarithmic-mean temperature difference |

| PFR | Plug-flow reactor |
| pp | Percentage point(s) |
| PSA / TSA | Pressure-swing / temperature-swing adsorption |
| RGibbs, RStoic, RPlug, HeatX, Sep | Aspen Plus Gibbs, stoichiometric and plug-flow reactor, heat-exchanger and component-splitter blocks |
| TEA | Techno-economic assessment |
| TRL | Technology readiness level |
| UA | Overall heat-transfer coefficient times area |

| Symbol | Meaning (unit) |
|---|---|
| $X$ | NH~3~ conversion (-) |
| $K$ | Equilibrium constant, standard state 1 bar, per mol NH~3~ (-) |
| $\Delta H_\mathrm{r}$, $\Delta G_\mathrm{r}^\circ$ | Reaction enthalpy, standard Gibbs energy of reaction (kJ/mol NH~3~) |
| $T$, $P$ | Temperature (degC or K), pressure (bar absolute) |
| $y_i$, $\varphi_i$ | Mole fraction, fugacity coefficient of species $i$ (-) |

| $\eta_\mathrm{LHV}$ | LHV efficiency (-), Eq. (16.1) |
| $Q$, $W$ | Heat duty, power (kW; positive = added to the process) |
| $W$ (Section 10) | Catalyst mass (kg) |
