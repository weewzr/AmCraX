# 43 Reproducibility

Every number in this report can be regenerated from the repository. The full command sequence, with the requirement of each step (Python only, Aspen Plus V15, or Word), is `docs/reproducing.md`, reproduced as Appendix F. This section summarises what makes the Phase 2 results reproducible and how to check them.

## 43.1 One basis, recorded in every output

Every Phase 2 result file carries a `provenance` object with the script that wrote it, the UTC time, the source type and the reference scenario it used: file, version (1.0.0), identifier, SHA-256 hash, exchange rate with its date (1.288444 SGD/USD, 20 November 2026) and CAPEX method (`cho2026_itemised_v1`). A test (`tests/test_phase2_reference.py`) compares the stored hash in each output with the live reference file, so an output computed on a different basis is detected. The baseline LCOH of 4.015461 USD/kg is pinned by tests in four workstreams.

## 43.2 Commands

All Phase 2 research outputs are regenerated in order by one script, which needs no Aspen Plus:

```powershell
. scripts\env.ps1
python scripts\research\run_all_phase2.py
python scripts\research\build_evidence_matrix.py
python -m pytest tests -q
python scripts\export_snapshot.py
python docs\technical_report\build_report.py
```

The stored Aspen Plus results (`results/simulations`, `results/research/aspen_kinetic`) are inputs to these steps, not outputs. Re-solving them needs a licensed Aspen Plus V15 (Appendix F, section 9.9). Random analyses use fixed seeds (20261123 and 20261124), so the Monte Carlo, Sobol and Latin-hypercube results are identical on every run. The browser simulator data are regenerated by `scripts/research/export_simulator_data.py` and checked by the frontend tests (`npm test` in `frontend/`).

## 43.3 What is preserved

The release of 23 November 2026 (version 1.0 of this report and the research results it quotes) is kept unchanged under the tag `amcrax-research-expansion-2026-11-23`, in `docs/technical_report/releases/2026-11-23/` and in `results/research_releases/2026-11-23/`. Appendix F, section 10 gives the commands and hashes that verify it. `results/research/reference_scenario/supersession.json` maps every changed quantity from that release to its current value with the reason.

## 43.4 What cannot be reproduced without outside access

The Aspen Plus runs need a licence. The literature values were read on 23 November 2026 from the sources listed in Section 44 and the `research/` data files, each with its URL or DOI and access date; a later reader may find a page changed or behind a paywall. Prices read from secondary displays (the ruthenium base price, the nickel cash price) are recorded with their date and grade and will not be reproduced by a later search.
