**Failing items by root cause** (each distinct cause listed once):

* **feed_section_enthalpy** (20 items): Different feed-section property models (a model-form difference in both directions, not a data error). Aspen uses PENG-ROB for the liquid, the vaporisation and the NH3-H2O dew point; the Python model uses the reference EOS for ammonia (CoolProp, Gao et al. 2020) and an ideal-liquid (Raoult) dew point. At identical states (Aspen baseline S1 -> S2) the Aspen vaporiser duty is +2.4 % relative to the reference EOS (739.46 vs 721.8 kW); the NH3 vapour residual enthalpy at S2 is -1.017 kJ/mol with PR (k_ij = 0) against -1.436 kJ/mol with the reference EOS, which is the more accurate model for pure-ammonia enthalpy. The vaporiser outlet temperature is set by the 0.2 mol% water and the VLE model: at 20.8 bar the dew point is 50.9 C for pure NH3, 52.7 C with PR k_ij = 0, 60.1 C with Raoult, 65.1 C with PR k_ij(NH3-H2O) = -0.25 and 65.9 C in Aspen; no reference NH3-H2O mixture model was available to arbitrate. Of the 20.8 kW baseline FEHE gap (Python 633.0, Aspen 612.2 kW) 8.7 kW come from the inlet temperature (dew point), 11.6 kW from the PR vs reference residual enthalpy at S2, 0.7 kW from the residual at S3 and -0.2 kW remain (ideal-gas cp sources, PR constants). The FS-<case> items therefore measure this model-form difference; they keep their 2 % tolerance and fail. Items: `FS-baseline`, `FS-baseline_no_hi`, `FS-opt_opt_conv`, `FS-opt_opt_eff`, `FS-opt_opt_h2`, `FS-opt_opt_heat`, `FS-opt_opt_lcoh`, `FS-opt_opt_lcoh_tp`, `FS-opt_par_1`, `FS-opt_par_2`, `FS-opt_par_3`, `FS-opt_par_4`, `FS-scn_fuel_cell_grade`, `FS-scn_high_pressure`, `FS-scn_high_recovery`, `FS-scn_high_temperature`, `FS-scn_low_pressure`, `FS-scn_low_recovery`, `FS-scn_low_temperature`, `FS-scn_tight_fehe`
* **kinetics_figure_predictions** (2 items): Takahashi (2016) microkinetic predictions: with W/F inferred from a single anchor point per catalyst (catalyst mass not reported; assumption) the PFR under-predicts conversion by more than 0.05 at diluted NH3 (p_NH3 0.25-0.3 atm) and with H2 co-feed (Figs. 3b, 5a, 5b), while the pure-NH3 temperature series agree; figure readings are approximate. Systematic, not tuned (developer guide 4.4). Items: `KIN-NI-PRED`, `KIN-RU-PRED`
